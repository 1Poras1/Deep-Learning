# Local LLM Chatbot

A chatbot built with Python, Streamlit, LangChain,
Ollama, and Gemma 2B.

## Requirements
- Python
- Ollama

## Setup

Install Python dependencies:

    pip install -r requirements.txt

Download the model:

    ollama pull gemma:2b

## Run

    python -m streamlit run app.py

Open http://localhost:8501 in your browser.
