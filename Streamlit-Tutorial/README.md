# Practical 3: Streamlit Tutorial

## Objective
To learn the basic functionalities of Streamlit and build an interactive web application using Python.

## Features
- Text, headings, and Markdown
- Interactive widgets and conditional logic
- Line and bar charts using NumPy and Pandas
- CSV file upload and table display
- Forms, images, and videos

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy

## How to Run
Install dependencies:
python -m pip install -r requirements.txt

Run the application:
python -m streamlit run app.py
